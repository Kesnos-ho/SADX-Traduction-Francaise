# SADX-Traduction-Française
Code pour le mod de Kesnos, basé sur le code créé par PkR et Kaori.

Une traduction française basée sur la traduction plus fidèle au script original de Windii, avec quelques corrections au niveau du texte pour les améliorations, les dialogues de tous les PNJ + une traduction graphique (l'interface et quelques éléments des niveaux).<br><br>Le mod est compatible avec les textures du jeu de base et les textures de la version Dreamcast, l'HD GUI 2 est obligatoire. Je vous conseille d'utiliser les voix japonaises pour jouer au jeu dans les meilleures conditions possibles.<br><br>Autres mods utilisés sur certains screens : <br><br><ul><li><a href="https://github.com/PiKeyAr/sadx-hd-gui" target="_blank">HD GUI 2</a></li><li><a href="https://github.com/PiKeyAr/sadx_dreamcast" target="_blank">DC Conversion</a><br></li><li><a href="https://github.com/PiKeyAr/sadx-onion-blur" target="_blank">Onion Skin Blur </a></li><li><a href="https://github.com/PiKeyAr/sadx-dc-lighting" target="_blank">Lantern Engine</a> </li><li><a href="https://gamebanana.com/mods/49943">Better Tails A.I.</a></li><li><a href="https://gamebanana.com/mods/49922">No Gloss</a></li><li><a href="https://gamebanana.com/mods/49978">ESRGAN-AI-HD Textures</a><br></li><li><a href="https://gamebanana.com/mods/9555">Dreamcast SADXWTR</a><br></li><li><a href="https://gamebanana.com/mods/290728">DX Characters Refined</a><br></li><li><a href="https://gamebanana.com/mods/324528">HD Rings</a><br></li><li><a href="https://gamebanana.com/mods/248045">DC Textures for DX Characters</a><br></li></ul><br><br>Mod conseillé<br><ul><li><a href="https://gamebanana.com/mods/499212">Extra Subtitles</a></li></ul><br>Mod obligatoire :<br><ul><li><a href="https://github.com/PiKeyAr/sadx-hd-gui" target="_blank">HD GUI 2</a><br><br></li></ul><br><a href="https://gamebanana.com/members/submissions/portfolio/1723576" class="SelectedElement">Mes autres traductions françaises.</a><br>N'hésitez pas à m'envoyer des messages privés si vous trouvez des erreurs. <a href="https://discord.gg/TPdsRYPFE8" target="_blank">Un serveur discord est aussi disponible à cette adresse en cas de besoin.</a><br>
